### Project Approval Web App

## Overview

This is a React-based web application designed for project approval and quality assessment. Users can fill out a project review form, provide electronic signatures, and generate a PDF document with the submitted information.

Its running @ https://project-approval-site.vercel.app/

## Features

✅ Fill out project details and review form  
✅ Capture electronic signatures using SignaturePad  
✅ Generate and download a PDF document based on the provided data  
✅ Validate inputs to ensure completeness before PDF generation

## Technologies Used

- **React** – Frontend framework
- **pdf-lib** – PDF generation and modification
- **file-saver** – For downloading the completed PDF

## How It Works

1. Fill out the **Project Review Form** with all required details.
2. Provide **digital signatures** in the designated signature fields.
3. Click the **submit button** to generate a PDF with the captured data.
4. Download the **completed PDF form** for record-keeping.
